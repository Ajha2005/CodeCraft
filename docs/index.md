# CodeCraft

**A Gamified DSA Practice Platform for Thapar Institute of Engineering & Technology**

Software Engineering — Project Blueprint & System Design Documentation

---

## What is CodeCraft?

CodeCraft is a DSA (Data Structures & Algorithms) practice platform built exclusively for students of Thapar Institute of Engineering and Technology. It differs from generic practice sites like LeetCode or Codeforces by wrapping problem-solving in a gamified layer: a fictional interactive map of the campus, divided into territories that students claim by solving problems well.

Difficulty and performance determine the size and value of the territory earned, and territories can only change hands through a voluntary, mutually-accepted 1v1 real-time contest — never by force.

## Core Loop

**Solve a problem → earn a performance score → claim or upgrade a territory on the map → optionally defend or challenge for territory in a live 1v1 contest → climb the leaderboard.**

## Key Differentiators

- Gamified learning via a fictional interactive map of Thapar, not just a problem list
- Territory ownership tied directly to problem difficulty and solving performance
- Voluntary, consent-based territory contests — no forced periodic defense, no theft
- Real-time 1v1 competitive coding, isolated per contest via WebSocket rooms
- College-wide and territory-specific leaderboards
- A defense-in-depth, multi-signal anti-cheating system
- Exclusively for verified Thapar students — no public signup
